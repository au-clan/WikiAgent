# Getting the Relevant Dataset
To obtain the necessary dataset for your project, follow these steps:

## 1. Download the Dataset:

You have two options to acquire the dataset:

**Option 1:** Run the following command in your terminal from the project's root folder. This command will automatically fetch the dataset and place it in the `data` directory.

        python data/get_data.py

**Option 2:** Alternatively, you can manually download the dataset from this [link](https://snap.stanford.edu/data/wikispeedia.html) and then move the downloaded files to the `data` directory.

## 2. Uncompress the Downloaded Files:

After obtaining the dataset, you will need to extract the contents. You can use your preferred method to uncompress the downloaded files directly into the `data` directory.
